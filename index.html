Fix C (iOS Safari / WebKit Texture Repaint Stall): iOS Safari (16.4+) has a known compositor texture bug where calling putImageData() on a canvas inside transformed parents fails to repaint. An offscreen buffer canvas is now used with drawImage(), and will-change: transform has been removed from drawer sheets. 4.
